## Notes

### Variables, constants and data types

A **variable** is a named storage location whose value can change while the program runs. A **constant** is a named value that is set once and never changes (e.g. `PI`, `VAT_RATE`). Constants make code easier to read and to change: edit the value in one place and the whole program updates.

| Data type | Stores | Pseudocode / example | Python type |
|---|---|---|---|
| **Integer** | whole numbers | `42`, `-7` | `int` |
| **Real** | numbers with a fractional part | `3.14`, `-0.5` | `float` |
| **Boolean** | True or False | `TRUE` | `bool` |
| **Character** | a single character | `'A'`, `'7'` | `str` of length 1 |
| **String** | text (a sequence of characters) | `'Hello'` | `str` |

Python has no separate char type: a character is just a string of length 1.

**Choosing a type:** age → integer; price → real; "is the user logged in?" → Boolean; first letter of a name → character; telephone number or postcode → **string** (you never do sums with them, and leading zeros such as 0034 must stay).

Using the right type matters because it decides how much memory is used, what operations are allowed, and how data is validated.

```python
PI = 3.14159                  # constant (by convention, capitals)
radius = 5                    # integer
circumference = radius * PI * 2
print(circumference)          # 31.4159
```

**Type conversion (casting):** `input()` in Python always gives a string, so convert it.

```python
age = int(input("Age: "))          # string -> integer
price = float(input("Price: "))    # string -> real
print("Fred" + str(18))            # integer -> string: Fred18
```

In Pearson pseudocode you state the type when reading: `RECEIVE Age FROM (INTEGER) KEYBOARD`. Mixed arithmetic is coerced automatically: integer + real gives real, e.g. 3 + 8.25 = 11.25. The `&` operator joins strings: `SEND 'Fred' & Age TO DISPLAY` outputs `Fred18`.

### Operators

**Arithmetic**

| Operation | Pseudocode | Python | Example |
|---|---|---|---|
| add / subtract | `+  -` | `+  -` | |
| multiply | `*` | `*` | |
| divide | `/` | `/` | 7 / 2 = 3.5 |
| power | `^` | `**` | 2 ^ 3 = 8 |
| **modulus** (remainder) | `MOD` | `%` | 17 MOD 5 = 2 |
| **integer division** | `DIV` | `//` | 17 DIV 5 = 3 |

MOD is used to test **even/odd** (`n MOD 2 = 0`), **divisibility** (`n MOD 3 = 0`) and to pull out the last digit (`n MOD 10`). DIV removes the last digit (`n DIV 10`).

**Relational** (give True or False): `=` equal to (Python: `==`), `<>` not equal (Python: `!=`), `<`, `<=`, `>`, `>=`.

**Logical:** `AND`, `OR`, `NOT` (Python: `and`, `or`, `not`). In an IF, `Age >= 13 AND Age <= 19` is true only if both parts are true. **Write the full condition both times**: not `Age >= 13 AND <= 19`.

### Input and output

| Task | Pseudocode | Python |
|---|---|---|
| output | `SEND 'Hello' TO DISPLAY` | `print("Hello")` |
| input a string | `RECEIVE Name FROM (STRING) KEYBOARD` | `name = input("Name: ")` |
| input an integer | `RECEIVE Age FROM (INTEGER) KEYBOARD` | `age = int(input("Age: "))` |
| random number 0 to n | `RANDOM(n)` | `random.randint(0, n)` (after `import random`) |

Always **prompt** the user so they know what to type, and respond to what they entered.

### Selection

Selection chooses which code runs, using a condition.

```
IF Mark >= 70 THEN
   SEND 'Distinction' TO DISPLAY
ELSE
   IF Mark >= 50 THEN
      SEND 'Merit' TO DISPLAY
   ELSE
      SEND 'Pass' TO DISPLAY
   END IF
END IF
```

```python
def grade(mark):
    if mark >= 70:
        return "Distinction"
    elif mark >= 50:
        return "Merit"
    else:
        return "Pass"
```

`elif` is Python's "else if"; it keeps nested decisions flat. Put the **tightest condition first** (70 before 50), because the first true branch wins. Indentation is part of Python syntax.

### Iteration (loops)

| Loop | Use when | Pseudocode | Python |
|---|---|---|---|
| **Count-controlled** | you know how many times | `FOR i FROM 1 TO 5 DO … END FOR` | `for i in range(1, 6):` |
| Count-controlled with step | counting in jumps | `FOR i FROM 0 TO 100 STEP 25 DO` | `for i in range(0, 101, 25):` |
| **Pre-condition** | might run zero times | `WHILE <cond> DO … END WHILE` | `while <cond>:` |
| **Post-condition** | must run at least once | `REPEAT … UNTIL <cond>` | `while True:` … `break` |
| Each item | go through every element | `FOR EACH Word FROM Words DO` | `for word in words:` |

Key points:
- Pearson `FOR i FROM 1 TO 5` includes **both ends**. Python's `range(1, 6)` stops **before** 6; `range(5)` gives 0 to 4.
- Python has no REPEAT … UNTIL. Imitate it with `while True:` and `break` when the stop condition is true.
- A WHILE loop needs something inside it that **changes** the condition, or it never ends.

```python
# sum numbers until 0 is entered (rogue value)
total = 0
n = int(input("Number (0 to stop): "))
while n != 0:
    total = total + n
    n = int(input("Number (0 to stop): "))
print("Total:", total)
```

```python
# post-condition: keep asking until the number is not negative
while True:
    v = int(input("Enter a number, 0 or more: "))
    if v >= 0:
        break
```

```python
# nested loops: a multiplication grid
for row in range(1, 3):
    for col in range(1, 4):
        print(row * col, end=" ")
    print()
# 1 2 3
# 2 4 6
```

A loop inside a loop runs the inner loop completely for each pass of the outer loop (here 2 × 3 = 6 times).

### Putting it together (typical Paper 2 task)

*Ask for the customer's age. Under 5 is free, under 16 costs £5, 65 or over costs £7, anyone else £10. Ask how many tickets and output the total.*

```python
# ticket price calculator
age = int(input("Age: "))
tickets = int(input("Number of tickets: "))

if age < 5:
    price = 0
elif age < 16:
    price = 5
elif age >= 65:
    price = 7
else:
    price = 10

total = price * tickets
print("Total cost: £" + str(total))
```

Mark-earning habits: a comment at the top, meaningful names, correct types, a prompt for each input, indentation, an output that makes sense.

### Readable code

- **Comments** explain what a section does (`#` in both Python and Pearson pseudocode).
- **Descriptive names**: `ticket_price`, not `tp`.
- **Indentation** shows structure (and Python requires it).
- Use **constants** instead of "magic numbers" like `0.2` appearing everywhere.

## Key terms and definitions

- **Variable**: a named location in memory that stores a value which can change while the program runs.
- **Constant**: a named location in memory that stores a value which cannot change while the program runs.
- **Data type**: the kind of data a variable holds (integer, real, Boolean, character, string), deciding what operations can be done on it.
- **Integer**: a whole number. **Real**: a number with a fractional part.
- **Boolean**: a data type with two values, True or False.
- **String**: a sequence of characters.
- **MOD (modulus)**: gives the remainder of a division. **DIV**: gives the whole-number part of a division.
- **Selection**: the program chooses which instructions to run depending on a condition.
- **Iteration**: repeating instructions in a loop.
- **Count-controlled loop**: repeats a set number of times. **Condition-controlled loop**: repeats while (or until) a condition is true.
- **Casting (type conversion)**: changing a value from one data type to another.

## Worked examples

**1. State the most suitable data type for each: (a) number of siblings, (b) average test score, (c) whether a user has paid, (d) a mobile phone number. Justify (d). [5]**

(a) Integer (b) Real (c) Boolean (d) String (1 each). Justification for (d): you do not perform calculations on it, and it may start with 0 or contain + or spaces (1).

**2. What is output? [3]**

```

SET B TO Num DIV 10
SET C TO A * B
SEND A & ' ' & B & ' ' & C TO DISPLAY
```

A = 7, B = 4, C = 28 → output `7 4 28`. Marks: A (1), B (1), C and formatted output (1).

**3. Write a program (any language or Pearson pseudocode) that outputs the 7 times table from 1 × 7 to 12 × 7. [3]**

```
FOR Index FROM 1 TO 12 DO
   SEND Index & ' x 7 = ' & Index * 7 TO DISPLAY
END FOR
```

```python
for i in range(1, 13):
    print(i, "x 7 =", i * 7)
```

Marks: a loop running 12 times (1), correct calculation (1), sensible output (1).

**4. A WHILE loop must run at least once. Explain which loop type to use and why. [2]**

A post-condition loop (REPEAT … UNTIL) (1), because the condition is tested at the end, so the body always runs at least once; a WHILE loop tests first and might not run at all (1).

## Common mistakes

- Using `=` as a test: in pseudocode `=` compares, in Python `==` compares and `=` assigns.
- Forgetting that `input()` returns a string; `"5" + "3"` gives `"53"`, not 8.
- Off-by-one errors with `range`: `range(1, 10)` gives only 1 to 9.
- Writing `x > 5 AND < 10` instead of `x > 5 AND x < 10`.
- Putting the loose condition first in an if/elif chain, so the tighter ones are never reached.
- Infinite loops: forgetting to update the variable in the loop, or forgetting to re-read input inside the loop.
- Calling something a constant when its value changes, or a variable when it never changes.
- Using integer for a phone number or real for a count of people.
