# Hardware: storage, memory and network hardware

> **In the exam:** Paper 1 Computer Systems (1 h 45 min, 75 marks). Worth about 8–12 marks. Typical questions: "state two differences between RAM and ROM" [2], "describe virtual memory" [3], "compare magnetic, optical and solid-state storage" [2–4], "describe how a [magnetic / optical / solid-state] device stores data" [3], "give two benefits and one drawback of cloud storage" [3], "what is a MAC address / IP address?" [2], "compare IPv4 and IPv6" [2–3] and "describe the role of a router" [2–3].

## What you need to know

- **Primary storage:** RAM and ROM; **volatile** and **non-volatile**; what each is used for.
- **Virtual memory:** what it is, why it is used and its effect on speed.
- **Secondary storage:** why it is needed; **magnetic, optical and solid-state** (how they work, examples, advantages and disadvantages).
- **Cloud storage:** how it works, benefits and drawbacks.
- **Network hardware:** **NIC**, **MAC address**, **IP address (IPv4 and IPv6)** and **router**.

## Notes

### Primary storage (memory the CPU can access directly)

| | RAM | ROM |
|---|---|---|
| Stands for | Random access memory | Read-only memory |
| Volatile? | **Volatile**: loses its contents when the power is off | **Non-volatile**: keeps its contents without power |
| Read/write | Read **and** write | Read only (normally cannot be changed) |
| Holds | The programs, data and part of the operating system **currently in use** | The **bootstrap** (start-up instructions that load the operating system) |
| Size | Large (e.g. 8–32 GB) | Small |

**Why is secondary storage needed?** RAM is volatile, so data would be lost when the computer is switched off. Secondary storage is **non-volatile** and keeps data and programs permanently. The CPU cannot access it directly; data is loaded into RAM first.

### Virtual memory

When **RAM is full**, the operating system uses part of the **secondary storage** (hard drive/SSD) as extra memory, called **virtual memory**.

1. Data (in blocks called **pages**) that is **not currently needed** is moved from RAM to virtual memory.
2. When that data is needed again it is moved back into RAM (and something else may be moved out).

This lets the computer run **more programs than RAM alone could hold**. But secondary storage is much **slower** than RAM, so if lots of swapping is needed the computer becomes **slow**. Adding more RAM reduces the use of virtual memory.

### Secondary storage

| Type | How it stores data | Examples |
|---|---|---|
| **Magnetic** | Surface is divided into tiny areas that are **magnetised** one way or the other (representing 1 and 0). A **read/write head** over **spinning platters** reads or changes them | Hard disk drive (HDD) |
| **Optical** | A **laser** shines on the surface of a spinning disc. **Pits and lands** (flat areas) reflect light differently, which is read as 1s and 0s. Writable discs use a laser to change a dye layer | CD, DVD, Blu-ray (Blu-ray uses a blue laser so holds more data) |
| **Solid state (flash)** | Uses **electronic circuits** (flash memory built from transistors) that trap or release electrical charge to represent 1 and 0. **No moving parts** | SSD, USB flash drive, SD card |

| Property | Magnetic (HDD) | Optical | Solid state |
|---|---|---|---|
| Capacity | Very large (terabytes) | Small (700 MB CD, about 4.7 GB DVD, 25 GB Blu-ray) | Large (up to terabytes) |
| Speed | Medium | Slowest | **Fastest** |
| Cost per GB | **Cheap** | Cheap discs | Most expensive |
| Durability | Moving parts: damaged if dropped | Scratches easily | **Very durable**, no moving parts |
| Portability | Large or heavy unless external | Light and portable | Small and light |
| Power / noise | More power, noisy | Moderate | **Low power**, silent |
| Typical use | Bulk storage, backup | Films, music, software distribution | Laptops, phones, USB sticks |

Flash memory can only be written a limited number of times (**wear**), though this is rarely a problem in normal use.

### Cloud storage

**Cloud storage** keeps data on **remote servers** owned by a company, which you access through the **internet**. Your data is often **replicated** across several servers.

| Benefits | Drawbacks |
|---|---|
| Access files from **any device, anywhere** with internet | Needs an **internet connection** (and a fast one for big files) |
| Easy to share files | **Security/privacy**: data could be hacked, and you rely on the provider |
| Automatic **backup**; data safe if your device is lost | Ongoing **subscription** cost for large storage |
| Easy to **increase capacity** (pay for more); no need to buy hardware | If the provider has a fault or goes out of business, you may lose access |

### Network hardware

**NIC (network interface card):** a component that **connects a device to a network**. It can be wired (Ethernet) or wireless (Wi-Fi). Each NIC is given a **MAC address** when it is made.

**MAC address (media access control):**
- A **unique** identifier for the NIC/device, set by the **manufacturer**.
- **48 bits**, usually shown as **6 pairs of hex digits**, e.g. `00:1A:2B:3C:4D:5E`.
- The first half identifies the **manufacturer**; the second half is a **serial number**.
- It does not normally change.

**IP address (Internet Protocol):**
- Identifies a device on a **network or the internet**, so data packets can be sent to the right place.
- **Allocated by the network/router/ISP**, so it **can change** when you join a different network (**dynamic**); some are **static** (fixed, e.g. for a web server).
- **IPv4:** **32 bits**, written as four numbers from **0 to 255** separated by dots, e.g. `192.168.1.10`. About 4.3 billion addresses (2³²), which is not enough for today's devices.
- **IPv6:** **128 bits**, written as **eight groups of four hex digits** separated by colons, e.g. `2001:0db8:85a3:0000:0000:8a2e:0370:7334`. Gives about 3.4 × 10³⁸ addresses. Created because IPv4 addresses are running out.

| | MAC address | IP address |
|---|---|---|
| Set by | Manufacturer | Network / ISP |
| Changes? | No (fixed to the device) | Yes (usually) |
| Format | 48-bit, hex | IPv4 32-bit denary / IPv6 128-bit hex |
| Identifies | The physical device (NIC) | The device's location on a network |

**Router:** connects **different networks** together (e.g. your home network to the internet).
- Receives **data packets**, reads the **destination IP address** and sends each packet on the best route.
- Often **assigns IP addresses** to devices on the local network.
- Often includes a **firewall** and a wireless access point so devices can connect by Wi-Fi.

## Key terms and definitions

- **RAM** — random access memory: volatile primary memory that holds the data and programs currently in use.
- **ROM** — read-only memory: non-volatile primary memory that stores the start-up instructions (bootstrap).
- **Volatile memory** — memory that loses its contents when the power is turned off.
- **Virtual memory** — part of secondary storage used as an extension of RAM when RAM is full.
- **Secondary storage** — non-volatile storage that keeps data permanently and is not directly accessed by the CPU.
- **Solid-state storage** — storage that uses flash memory with no moving parts.
- **Cloud storage** — data storage on remote servers accessed through the internet.
- **NIC** — network interface card: hardware that allows a device to connect to a network.
- **MAC address** — a unique 48-bit hardware address assigned to a NIC by its manufacturer.
- **IP address** — an address allocated to a device on a network, used to route data packets to it.
- **Router** — a device that sends data packets between networks, using IP addresses.

## Worked examples

**1. State two differences between RAM and ROM. [2]**

RAM is volatile but ROM is non-volatile [1]. RAM can be read and written, but ROM is read-only [1]. (Also: RAM holds programs in use; ROM holds the start-up program.)

**2. Explain why a computer slows down when it uses a lot of virtual memory. [3]**

Virtual memory is part of secondary storage used when RAM is full [1]. Data has to be swapped between RAM and secondary storage [1]. Secondary storage is much slower to access than RAM [1].

**3. A photographer carries a laptop and wants to store photos. Compare an SSD with a hard disk drive. [4]**

The SSD has no moving parts, so is more durable if the laptop is knocked [1] and silent/uses less power [1]. The SSD is faster to read and write [1], but costs more per GB so the HDD gives more capacity for the same money [1].

**4. Describe two differences between an IP address and a MAC address. [2]**

A MAC address is set by the manufacturer and does not change, but an IP address is allocated by the network and can change [1]. A MAC address is 48 bits in hex, but an IPv4 address is 32 bits in denary [1].

## Common mistakes

- Saying "RAM stores data permanently" or "ROM loses its data". Volatile = loses data when power off.
- Confusing **virtual memory** with **cache** or saying it is "extra RAM chips". It is part of the **hard drive/SSD**.
- Saying an SSD is "faster because it has more memory". It is faster because there are **no moving parts**.
- Saying optical discs store data "using magnets", or that magnetic drives use a laser.
- Giving a security risk for cloud storage without a reason ("hackers" alone). Say that the data is held by a third party / on remote servers.
- Writing an IPv4 address with a number over **255** (e.g. 192.168.1.300 is invalid).
- Saying the MAC address is allocated by the router, or that the IP address never changes.
- Saying a router "connects computers in a LAN". A **switch** does that; a router connects **networks**.
