## Notes

### Why use data structures?

A single variable holds one value. A **data structure** holds a collection of related values under one name, so you can store many items and process them with a loop instead of writing 50 separate variables.

### One-dimensional arrays (lists)

An **array** is a fixed-size, ordered collection of items **of the same data type**, accessed by an **index** (position). In the Pearson specification, **indices start at 0**. Python uses a *list*, which works the same way for our purposes.

| Idea | Pearson pseudocode | Python |
|---|---|---|
| create | `SET Names TO ['Ann', 'Ben', 'Cy']` | `names = ["Ann", "Ben", "Cy"]` |
| read item | `Names[1]` (gives 'Ben') | `names[1]` |
| change item | `SET Names[1] TO 'Bea'` | `names[1] = "Bea"` |
| number of items | `LENGTH(Names)` | `len(names)` |
| add to the end | `Names & 'Dev'` (append operator) | `names.append("Dev")` |
| all items | `FOR EACH Name FROM Names DO` | `for name in names:` |
| by index | `FOR Index FROM 0 TO LENGTH(Names) - 1 DO` | `for i in range(len(names)):` |

The **last index is `LENGTH − 1`**. A 4-item array has indices 0, 1, 2, 3; asking for index 4 is a **runtime error** (index out of range).

```python
marks = [56, 72, 48, 90]

total = 0
for m in marks:
    total = total + m
print(total / len(marks))     # average: 66.5
print(max(marks), min(marks)) # 90 48

# search for a value and report where it is
for i in range(len(marks)):
    if marks[i] == 48:
        print("48 is at index", i)     # index 2
```

**Why use an array?** Store many related values under one name, process them with a loop, and add or change items easily, so the code is shorter and easier to maintain than separate variables.

### Two-dimensional arrays

A **2D array** is a table: an array whose items are themselves arrays. You need **two indices**: row and column. Pearson pseudocode writes `Array[RowIndex, ColumnIndex]`; Python writes `grid[row][col]`.

```python
grid = [[1, 2, 3],
        [4, 5, 6],
        [7, 8, 9]]

print(grid[1][2])         # row 1, column 2 -> 6
print(len(grid))          # number of rows: 3
print(len(grid[0]))       # number of columns: 3

# total of every element: nested loops
total = 0
for r in range(len(grid)):
    for c in range(len(grid[r])):
        total = total + grid[r][c]
print(total)              # 45
```

Pearson pseudocode: `SET ArrayClassMarks[2,4] TO 92` stores 92 in row 2, column 4.

Outer loop = rows, inner loop = columns. To total one **row**, loop over the columns with the row fixed; to total one **column**, loop over the rows with the column fixed.

Typical uses: noughts and crosses board, seating plan, a class's marks (student × test), a game map.

### Records

A **record** groups **different data types** about one thing, each part being a named **field**. In an array all items are the same type; in a record they can differ.

| Field | Type | Value |
|---|---|---|
| name | string | "Ana" |
| age | integer | 15 |
| form | string | "10B" |

In Python, use a dictionary (or a class):

```python
student = {"name": "Ana", "age": 15, "form": "10B"}
print(student["name"])       # Ana
student["age"] = 16          # update one field

students = [{"name": "Ana", "mark": 72},
            {"name": "Luis", "mark": 55}]     # a list of records
for st in students:
    print(st["name"], st["mark"])
```

| | Array | Record |
|---|---|---|
| Items | all the **same** data type | can be **different** types |
| Access by | index (position) | field name |
| Use for | a list of similar values (e.g. 30 marks) | one entity's details (e.g. one student) |

A **file of records** (e.g. one line per student) or an array of records is how a program stores a whole table of people or products.

### Strings

A **string** is a sequence of characters. Each character has an index starting at 0. You can join strings, find their length and pick out parts.

| Task | Pearson pseudocode | Python | Result for `w = "Computer"` |
|---|---|---|---|
| length | `LENGTH(Word)` | `len(w)` | 8 |
| first character | `Word[0]` | `w[0]` | `'C'` |
| last character | `Word[LENGTH(Word) - 1]` | `w[len(w)-1]` or `w[-1]` | `'r'` |
| substring (slice) | | `w[0:3]` (index 0 up to, not including, 3) | `'Com'` |
| join (concatenate) | `'Hello' & ' ' & 'World'` | `"Hello" + " " + "World"` | `'Hello World'` |
| change case | | `w.upper()`, `w.lower()` | `'COMPUTER'`, `'computer'` |
| find position | | `w.find("p")` (returns -1 if absent) | 3 |
| contains? | | `"put" in w` | True |
| split | | `"a,b,c".split(",")` | `['a','b','c']` |
| character ↔ code | | `ord("A")` is 65, `chr(66)` is `'B'` | |

Strings cannot be changed one character at a time in Python (`w[0] = "c"` is an error); you build a new string. Pearson pseudocode joins mixed types with `&`: `SEND 'Fred' & Age TO DISPLAY` gives `Fred18`.

```python
# count the vowels in a word
vowels = 0
for ch in "education":
    if ch in "aeiou":
        vowels = vowels + 1
print(vowels)                       # 5

# reverse a string by building a new one
rev = ""
for ch in "abc":
    rev = ch + rev
print(rev)                          # cba

# palindrome check
word = "racecar"
print(word == word[::-1])           # True
```

**Using string handling for validation and formatting:** check `len(password) >= 8`, check `"@" in email`, convert input to lower case before comparing (`answer.lower() == "yes"`), and use `.isdigit()` to check a string contains only digits.

### File handling

Files let data **persist** (stay saved) after the program ends. Text files store lines of text.

**Pearson pseudocode:** `READ MyFile.txt Record` reads one record from the file into a variable; `WRITE MyFile.txt Answer1, Answer2` writes a record. Each READ or WRITE deals with one record.

**Python:**

```python
# write (mode "w" creates or overwrites the file)
f = open("scores.txt", "w")
f.write("Ana,72\n")                 # \n ends the line
f.write("Luis,55\n")
f.close()                           # always close the file

# read, line by line
f = open("scores.txt", "r")
for line in f:
    line = line.strip()             # remove the newline
    parts = line.split(",")         # ['Ana', '72']
    print(parts[0], int(parts[1]))  # convert the mark to an integer
f.close()

# append (mode "a" adds to the end without erasing)
with open("scores.txt", "a") as f:
    f.write("Eva,90\n")
```

| Mode | Meaning |
|---|---|
| `"r"` | read (error if the file does not exist) |
| `"w"` | write: creates the file, **erases** existing contents |
| `"a"` | append: adds to the end |

`with open(...) as f:` closes the file for you. Data read from a text file is always a **string**: convert numbers with `int()` or `float()`. Opening a file that does not exist in read mode causes a **runtime error** (`FileNotFoundError`).

### Choosing a structure

- A list of similar items (marks, names) → **1D array**.
- A table (rows and columns of the same type) → **2D array**.
- Different details about one thing → **record**.
- Data that must survive between runs → **file**.

## Key terms and definitions

- **Data structure**: a way of organising and storing a collection of related data items.
- **Array**: a fixed-size collection of items of the same data type, each accessed by an index.
- **Index**: the position of an item in an array or string (starts at 0).
- **Two-dimensional array**: an array of arrays, giving a table of rows and columns; each item needs two indices.
- **Record**: a data structure made of a number of named fields, which can have different data types.
- **Field**: one named item of data in a record.
- **String**: a sequence of characters.
- **Concatenation**: joining two or more strings together.
- **Substring**: a part of a string.
- **Text file**: a file that stores data as lines of readable characters, used to store data permanently.

## Common mistakes

- Counting from 1: the first item is at index **0** and the last at `LENGTH − 1`.
- Index out of range: in pseudocode, `FOR Index FROM 0 TO LENGTH(List)` goes one too far; it must be `LENGTH(List) - 1`. (In Python, `range(len(list))` is already correct.)
- Mixing up row and column in a 2D array (row first, column second).
- Forgetting that file data is text: `"72" + 1` is an error; use `int()`.
- Opening a file with `"w"` when you meant `"a"`, which erases it.
- Forgetting `\n` between lines when writing, and `.strip()` when reading.
- Forgetting to `close()` the file.
- Saying "an array can store different data types" in the exam; in the specification it is the **same** type, and a record has mixed types.
- Slicing: `w[0:3]` gives 3 characters (indices 0, 1, 2), not 4.
