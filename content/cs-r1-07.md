# The internet, cybersecurity and emerging technologies

> **In the exam:** Cambridge IGCSE Computer Science 0478 **Paper 1 (Computer Systems, 1 h 45, 75 marks)** covers syllabus section 5 (The internet and its uses), 4.x/5.x security threats and 6 (Automated and emerging technologies). Expect 1-mark state/identify items, 2-mark "describe/explain" items and a 4–6 mark question on a threat and how to prevent it. Questions are almost always set in a scenario (a school, a bank, an online shop) so you must apply your answer.

## What you need to know

- The difference between the **internet** and the **World Wide Web (WWW)**.
- What a **URL**, **HTTP/HTTPS**, **web browser**, **web server**, **IP address** and **DNS** are and how a web page is retrieved.
- **Cookies**: purpose, **session** and **persistent** cookies, and what they are used for.
- **Digital currency** and **blockchain** (how it works and why it is hard to alter).
- Cybersecurity threats: **brute-force attack**, **data interception**, **DDoS**, **hacking**, **malware** (virus, worm, Trojan horse, spyware, adware, ransomware), **phishing**, **pharming**, **social engineering**.
- Ways to keep data safe: **access levels**, **anti-malware**, **authentication** (passwords, biometrics, two-step verification), **firewalls**, **proxy servers**, **SSL/TLS**, **privacy settings**, **user training**.
- **Automated systems**: sensors, microprocessor, actuators and feedback.
- **Robotics**: characteristics, uses, advantages and disadvantages.
- **Artificial intelligence**: characteristics, **expert systems** and **machine learning**.

## Notes

### Internet vs World Wide Web

| | Internet | World Wide Web |
|---|---|---|
| What it is | The **global network of networks** (the infrastructure: cables, routers, servers) | A **collection of web pages and websites** accessed *using* the internet |
| Uses | Carries web, email, streaming, online games, file transfer | Pages are written in **HTML** and viewed in a **browser** |

The web is just one service that runs on the internet. Mixing them up is a classic lost mark.

### Getting a web page: URL, HTTP, browser, DNS

- A **URL** (Uniform Resource Locator) is the text address of a web page, e.g. `https://www.example.com/shop/shoes.html`. It has three parts: the **protocol** (`https`), the **domain name** (`www.example.com`) and the **path/file name** (`/shop/shoes.html`).
- **HTTP** (hypertext transfer protocol) is the protocol used to request and send web pages. **HTTPS** is the same but **encrypted using SSL/TLS**, so data intercepted cannot be read.
- A **web browser** is software that requests a page, receives the HTML and **renders** (displays) it. It also stores bookmarks and history, holds cookies and runs multiple tabs.
- A **web server** stores the website and sends it when asked.
- Every device on the internet has an **IP address**. People use domain names, so a **DNS (Domain Name System)** server converts the domain name into the IP address.

**Steps when you type a URL:**

1. The browser sends the URL's domain name to a **DNS server**.
2. The DNS server looks it up and returns the **IP address** (if it does not have it, it asks another DNS server).
3. The browser sends an HTTP(S) request to the **web server** at that IP address.
4. The web server sends back the **HTML** (and other files).
5. The browser **renders** the page.

### Cookies

A **cookie** is a **small text file stored by the browser** on your device when you visit a website.

| Type | Lifetime | Use |
|---|---|---|
| **Session cookie** | Held in memory; **deleted when the browser is closed** | Keep items in a shopping basket, keep you logged in during a visit |
| **Persistent cookie** | Stored on the hard drive until an **expiry date** or you delete it | Remember login details/preferences, track browsing to show targeted adverts, count visits |

Cookies are not programs and cannot spread a virus, but tracking cookies raise **privacy** concerns.

### Digital currency and blockchain

- **Digital currency** exists only electronically; there are no notes or coins. **Cryptocurrency** (e.g. Bitcoin) is a digital currency that uses **encryption** and is usually **decentralised** (no bank or government controls it).
- A **blockchain** is a **digital ledger** (record) of transactions, stored as a **chain of blocks** copied across many computers. Each block holds the **transaction data**, a **timestamp**, its own **hash** and the **hash of the previous block**.
- Because each block contains the previous block's hash, **changing one block changes its hash and breaks every later link**, so tampering is easily spotted. This makes the ledger very secure and transparent.
- Drawbacks of cryptocurrency: value can change a lot, it is used in crime, transactions cannot easily be reversed, and mining uses a lot of electricity.

### Cybersecurity threats

| Threat | What it is | Key point |
|---|---|---|
| **Brute-force attack** | A program tries **every possible combination** of characters to guess a password | Longer, more varied passwords take far longer; account lock-out stops it |
| **Data interception** | Data is **captured while travelling** across a network (a **packet sniffer**), e.g. on public Wi-Fi | **Encryption** makes the data unreadable |
| **DDoS** (distributed denial of service) | A huge number of requests from many infected computers (a **botnet**) floods a server so it **cannot respond** to real users | Website goes offline; **firewall/proxy** helps filter traffic |
| **Hacking** | **Unauthorised access** to a computer or network, to steal, delete or change data | Strong passwords, **firewall**, **access levels** |
| **Malware** | **Malicious software**: see below | **Anti-malware**, updates |
| **Phishing** | A fake **email/text** pretending to be a real organisation, with a link to a fake site to steal details | Look for poor spelling, generic greeting, suspicious link |
| **Pharming** | **Malicious code installed on a computer or server redirects** you from the real website to a **fake website**, even when you type the right address | Anti-malware; check for HTTPS padlock |
| **Social engineering** | **Tricking people** into giving up data or access (a fake phone call from "IT support") | Staff training |

**Malware types**

- **Virus**: code that **attaches to a file** and copies itself when the file is run; it needs a user to open it, and can delete or corrupt files.
- **Worm**: **self-replicating**, spreads across a network **without a host file or user action**, using up bandwidth.
- **Trojan horse**: appears to be **legitimate software** but contains malware; it does not replicate.
- **Spyware**: secretly **records keystrokes/activity** (key logger) and sends it to a criminal.
- **Adware**: displays unwanted adverts and may track browsing.
- **Ransomware**: **encrypts files** and demands payment to unlock them.

Be careful: **phishing** relies on the user clicking, **pharming** redirects *without* the user making a mistake in the URL.

### Keeping data safe

| Method | How it helps |
|---|---|
| **Access levels** | Different users get different rights (read only, edit, admin), limiting damage and hacking |
| **Anti-malware / anti-virus** | **Scans** files, compares with known malware, **quarantines or deletes** it; must be **updated** often |
| **Authentication** | Proves who you are: **password** (strong, changed regularly), **biometrics** (fingerprint, face), **two-step verification** (password then a code sent to your phone) |
| **Firewall** | Examines **incoming and outgoing traffic** against rules and **blocks** unauthorised traffic; can be hardware or software |
| **Proxy server** | Sits between the user and the internet; **filters** requests, hides the user's IP address, can cache pages and block sites, and absorbs some attacks |
| **SSL/TLS** | Encrypts data between browser and server; shown by `https` and a **padlock** |
| **Automatic software updates** | Fix **security holes** (patches) |
| **Privacy settings** | Control who can see your information on social media/browser |
| **Training** | Staff learn to spot phishing and social engineering |

### Automated systems, robotics and AI

**Automated systems** use **sensors** to collect data, a **microprocessor** to compare it with stored values, and **actuators** to take action, with the result **fed back** to the sensor (a feedback loop). Examples: greenhouse (temperature/humidity sensor, heater and window motors), automatic street lights (light sensor), central heating, antilock brakes.

**Robotics** is the branch of computing that designs and uses **robots**: a robot has a **mechanical structure**, **sensors** and a **processor/program** it follows, and may have **actuators** to move. Used in **factories** (welding, painting), **exploring** dangerous or remote places, **surgery**, **warehouses** and **home** (robot vacuums).

| Advantages | Disadvantages |
|---|---|
| Work 24/7 without breaks or pay; very **accurate and consistent** | **Expensive** to buy and maintain |
| Can do **dangerous** or repetitive tasks | **Job losses** for people |
| Less human error | Cannot cope easily with **unexpected situations** |

**Artificial intelligence (AI)** is a computer system able to perform tasks that normally need human intelligence. Its main characteristics: it collects **data and the rules** for using the data, **reasons** with them to reach conclusions, and can **learn and adapt**.

- **Expert system**: gives advice like a human expert (medical diagnosis, fault-finding, tax advice). Parts: **knowledge base** (facts), **rule base** (IF–THEN rules), **inference engine** (reasons with the rules to reach a conclusion) and a **user interface** (user enters questions, system gives a recommendation and may explain how it reached it).
- **Machine learning**: the system **learns from data/experience** and **improves its performance without being explicitly reprogrammed**. Examples: spam filters, recommendations on a streaming service, self-driving cars improving as they drive.

## Key terms and definitions

- **Internet:** the global network of interconnected networks.
- **World Wide Web:** a collection of web pages stored on web servers, accessed through the internet using a browser.
- **URL:** the text address of a web page or file.
- **DNS:** a system that translates a domain name into the IP address of the web server.
- **Cookie:** a small text file stored on a user's computer by a website that remembers information about the user.
- **Blockchain:** a decentralised digital ledger made of linked blocks, each containing a hash of the previous block.
- **Phishing:** a fraudulent email or message sent to trick the user into giving personal data.
- **Pharming:** malicious code that redirects a user to a fake website to steal personal data.
- **DDoS attack:** many computers flood a server with requests so that it cannot serve genuine users.
- **Ransomware:** malware that encrypts data and demands payment for the key.
- **Firewall:** software or hardware that monitors network traffic and blocks unauthorised access according to rules.
- **Machine learning:** a computer system's ability to learn from data and improve without being explicitly programmed.

## Worked examples

**1.** *Describe how a web page is retrieved when a user types the URL into a browser. [4]*

- The browser sends the **domain name** to a **DNS server** [1]
- The DNS server returns the **IP address** of the web server [1]
- The browser sends a **request** to the web server at that IP address [1]
- The web server sends the page's **HTML**, which the browser **renders** [1]

**2.** *A bank's customers received emails asking them to click a link and enter their login details. State what this attack is called and give two ways customers can avoid it. [3]*

- **Phishing** [1]
- Do not click links in unexpected emails / go to the bank's website by typing the address yourself [1]
- Check the sender address, greeting and spelling; or enable two-step verification [1]

**3.** *Explain how a DDoS attack can stop a company's website working. [3]*

- The attacker uses many infected computers (a **botnet**) [1]
- They send **huge numbers of requests** to the web server at the same time [1]
- The server is **overloaded** and cannot respond to genuine users, so the site goes down [1]

**4.** *A greenhouse uses an automated system. Describe the role of the sensor, the microprocessor and the actuator. [3]*

- The **sensor** measures the temperature and sends the data to the microprocessor [1]
- The **microprocessor** compares the value with the stored value and decides whether action is needed [1]
- The **actuator** (e.g. a motor) opens the window or switches on the heater [1]

## Common mistakes

- Writing that the **internet and the web are the same thing**.
- Saying a cookie is a **virus** or "a program". It is a **text file**.
- Mixing up **phishing** (fake message to the user) and **pharming** (redirects to a fake site).
- Saying a firewall "stops viruses". It filters **network traffic**; **anti-malware** deals with viruses.
- Saying "a virus **spreads by itself** across a network". That is a **worm**; a virus needs a host file.
- Giving vague answers like "makes it more secure". Say **what it does** (e.g. "encrypts the data so it cannot be read if intercepted").
- Saying a DDoS "hacks into the server". It **overloads** the server; it does not steal data.
