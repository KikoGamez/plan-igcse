# Past paper · Writing timed

> **Goal:** Write the 0520 Writing paper (short task + a 130–150-word task) under timed conditions, then check it against the assessment criteria and log every language error.

## Before you start

- **Paper:** a recent 0520 Writing paper (May/June or Oct/Nov 2024 or 2025) you have not done, with its mark scheme (it contains the assessment criteria/marking grids). Your teacher can provide them from the Cambridge School Support Hub.
- Black pen, lined paper, timer. **No dictionary, no phone, no notes.**
- Have your error log open only for the checking stage.

## Exam format reminder

- Check the paper cover for the exact duration, number of tasks and word counts. In this plan you prepare for a **short task** (an email/message covering given points) and a **longer task of about 130–150 words** where you **choose one** of the options.
- Each task gives you bullet points or prompts — **every one must be covered**.
- Assessment (general): **communication** of the required information; **range** of vocabulary, structures and tenses; **accuracy**. The mark scheme gives band descriptors — read them before you start marking.
- Suggested timing: spend proportionally more time on the long task. Leave 5 minutes at the end to check.

## How to do it

1. **0–3 min** — Read all tasks. For the long task, choose the option where you can answer **every** bullet confidently in the right tenses (not the one with the topic you like most).
2. **Short task** — Plan in 1 minute (one key word per bullet, tense noted), write, check.
3. **Long task** — Plan for 3–4 minutes: one paragraph per bullet, the tense each bullet needs, one opinion + reason per paragraph, and 2–3 range features (e.g. *si* + imparfait + conditionnel, *après avoir* + participle, *ce qui/ce que*).
4. Write. Keep a rough count: ~35 words per paragraph if there are four bullets.
5. **Last 5 minutes** — CAGE check: **C**onjugation, **A**greement, **G**ender, **E**xtras (accents, missing *ne*, *de* after negatives).
6. **Remaining session time** — check against the criteria (below).

## Exam technique for this paper

- **Answer the bullet that is asked**, in the tense it implies:
  - *Décrivez…* past event → passé composé + imparfait.
  - *Qu'est-ce que vous pensez de… ?* → present opinion + reason.
  - *Quels sont vos projets… ?* → futur proche / futur simple.
  - *Qu'est-ce que vous aimeriez… ?* → conditionnel.
- **Develop each bullet**: a fact + a detail + an opinion with *parce que*. That is communication *and* range.
- **Write what you can say correctly.** Simple, accurate French beats ambitious, broken French. Use "wow" structures only if you are sure of them.
- **Register:** *tu* for a friend, *vous* for a company/hotel/teacher; keep it consistent.
- **Word count:** within the limits. Far under = undeveloped; far over = more errors and lost time. Don't count every word in the exam — count lines.
- **Don't recycle a memorised essay** that doesn't fit the bullets; adapt prepared phrases instead.

## Checklist while marking

Read the mark scheme's band descriptors, then go through your work with three highlighters:

1. **Communication** — tick each bullet. Is it covered, clear, and in the right tense? A missing or unclear bullet is the biggest loss.
2. **Range** — highlight: different tenses, opinions + reasons, connectives, complex structures (relative pronouns, *si* clauses, infinitive constructions), topic-specific vocabulary. Is there variety, or is every sentence *C'est… / J'aime…*?
3. **Accuracy** — underline every error. Classify:
   - **V** verb form / tense (*je suis allé* vs *j'ai allé*)
   - **A** agreement (adjective, participle)
   - **G** gender / article
   - **S** spelling / accent
   - **W** wrong word / Spanish interference
   - **O** word order (*ne… pas*, pronouns, adjectives)
4. Place yourself in a band for each criterion using the descriptors. Be honest; if you can, ask your French teacher to mark one task too.
5. **Error log:** each error with its correct version and the rule (e.g. "*aller* takes *être*: *je suis allée*"). If the same type appears 3+ times, make it a weekly-review priority.
6. Rewrite the weakest paragraph correctly.

## Quick-fire revision

- *Être* verbs: *aller, venir, arriver, partir, entrer, sortir, monter, descendre, naître, mourir, rester, tomber, retourner, rentrer, revenir, devenir* + reflexives → agreement.
- Irregular participles: *eu, été, fait, pris, mis, vu, bu, lu, dit, écrit, pu, voulu, dû*.
- Future/conditional stems: *ser-, aur-, ir-, fer-, pourr-, voudr-, devr-, viendr-, verr-*.
- *Si* + présent → futur; *si* + imparfait → conditionnel.
- After a negative: *pas de / pas d'* (*je n'ai pas de voiture*).
- *Depuis* + present tense.
- Openers/closers: *Salut / Cher, Chère / Madame, Monsieur* · *À bientôt / Cordialement*.
- Range phrases: *ce qui m'a plu, c'était… · après avoir mangé… · avant de partir… · il faut que je fasse… · j'espère que… · je viens de* + inf. (*I have just*).
