# Algebra: quadratic equations

> **In the exam:** In **both papers**, every series. Paper 2: solve by factorising (2–3 marks), complete the square in the form (x + p)² + q or a(x + p)² + q (2–3 marks), sometimes "hence solve" in surd form. Paper 4: the quadratic formula with answers to 2 decimal places (4 marks), and quadratics that come out of a problem (area of a shape, algebraic fractions, speed and time) worth 6–8 marks in total.

## What you need to know

- (Extended) Solve quadratic equations by factorisation, completing the square and by use of the quadratic formula.
- (Extended) Write a quadratic expression in the form a(x + p)² + q, and use it to find the turning point of y = ax² + bx + c.
- (Extended) Solve equations that lead to quadratics, including those involving algebraic fractions.
- Form a quadratic equation from a problem, solve it, and interpret the solutions (reject impossible ones).

## Notes

### Step one: rearrange to = 0

Every method needs ax² + bx + c = 0. Collect all terms on one side first.
x(x + 2) = 35 → x² + 2x − 35 = 0.

### Method 1: factorising (exact answers, Paper 2)

- x² − 5x − 14 = 0 → (x − 7)(x + 2) = 0 → x = 7 or x = −2.
- 2x² + 5x − 3 = 0 → (2x − 1)(x + 3) = 0 → x = ½ or x = −3.
- x² = 7x → x² − 7x = 0 → x(x − 7) = 0 → **x = 0** or x = 7. Never divide by x — you lose x = 0.
- 4x² − 9 = 0 → (2x − 3)(2x + 3) = 0 → x = ±1.5.

If (A)(B) = 0, then A = 0 or B = 0. This only works when the right side is **zero**.

### Method 2: the quadratic formula (when it does not factorise)

For ax² + bx + c = 0:

**x = (−b ± √(b² − 4ac)) / (2a)**

(The formula is printed on the Extended formula list, but know it by heart and use it accurately.)

Example: 3x² − 7x − 2 = 0, a = 3, b = −7, c = −2.
x = (7 ± √(49 + 24)) / 6 = (7 ± √73)/6 → x = 2.59 or x = −0.26 (2 d.p.).

- Write the substitution down in full: **M1** for "√((−7)² − 4 × 3 × (−2))" and **M1** for "(7 ± √…)/(2 × 3)".
- Bracket negative values: (−7)² = 49, not −49.
- "Give your answers correct to 2 decimal places" → write more figures first (2.5906…), then round. Wrong rounding loses the A mark.
- The fraction line goes under the **whole** numerator, including −b.
- Non-calculator: leave in surd form and simplify. x² − 4x − 1 = 0 → x = (4 ± √20)/2 = (4 ± 2√5)/2 = **2 ± √5**.

### Method 3: completing the square

**a = 1:** x² + bx + c = (x + b/2)² − (b/2)² + c.
- x² + 6x − 5 = (x + 3)² − 9 − 5 = **(x + 3)² − 14**.
- x² − 10x + 18 = (x − 5)² − 25 + 18 = **(x − 5)² − 7**.

**a ≠ 1:** take a out of the x² and x terms first.
2x² − 12x + 7 = 2(x² − 6x) + 7 = 2[(x − 3)² − 9] + 7 = **2(x − 3)² − 11**.

**Solving by completing the square:** (x + 3)² − 14 = 0 → (x + 3)² = 14 → x + 3 = ±√14 → **x = −3 ± √14**.

**Turning point:** for y = (x + p)² + q, the turning point is **(−p, q)**. For y = x² + 6x − 5 = (x + 3)² − 14, the minimum point is (−3, −14). If a > 0 it is a minimum; if a < 0 it is a maximum. The line of symmetry is x = −p.

### Equations that lead to quadratics

**Algebraic fractions:** multiply every term by all the denominators.
3/x + 2/(x + 1) = 1 → 3(x + 1) + 2x = x(x + 1) → 5x + 3 = x² + x → x² − 4x − 3 = 0 → x = 2 ± √7 = 4.65 or −0.65.

**Problems with shapes:** a rectangle has length (x + 3) cm, width (x − 1) cm and area 32 cm².
(x + 3)(x − 1) = 32 → x² + 2x − 35 = 0 → (x + 7)(x − 5) = 0 → x = 5 (x = −7 is rejected because lengths must be positive). State why you reject a solution.

"Show that … simplifies to 2x² − 7x − 3 = 0" — every step must be shown, and the final line must match exactly. You can then use the given equation in the next part even if you could not show it.

### Which method?

| Situation | Method |
|---|---|
| Paper 2, "solve" with integers or simple fractions | factorise |
| "Give answers to 2 decimal places" / 3 s.f. | formula |
| "Write in the form (x + p)² + q", turning point, exact surd answer | complete the square |

## Worked examples

**1.** Solve x² − 5x − 14 = 0. [3]

- (x − 7)(x + 2) — **B2** (B1 for brackets giving two of the three terms correctly)
- **x = 7, x = −2** — **B1**

**2.** Solve 3x² − 7x − 2 = 0. Show all your working and give your answers correct to 2 decimal places. [4]

- √((−7)² − 4(3)(−2)) or better — **B1**
- (−(−7) ± √q)/(2 × 3) — **M1** (for p + √q or p − √q over 2 × 3)
- **x = 2.59** — **A1**, **x = −0.26** — **A1**

**3.** (a) Write x² + 6x − 5 in the form (x + p)² + q. [2]
(b) Hence solve x² + 6x − 5 = 0, giving your answers in surd form. [2]

- (a) **(x + 3)² − 14** — **B2** (B1 for p = 3 or q = −14)
- (b) x + 3 = ±√14 — **M1**; **x = −3 ± √14** — **A1**

**4.** A rectangle has length (x + 3) cm and width (x − 1) cm. Its area is 32 cm². Find the value of x. [4]

- (x + 3)(x − 1) = 32 — **M1**
- x² + 2x − 35 = 0 — **A1**
- (x + 7)(x − 5) = 0 — **M1**
- **x = 5** (only) — **A1**

## Common mistakes

- Using factorising or the formula on an equation not rearranged to = 0.
- Dividing both sides by x and losing the solution x = 0.
- Formula: −b when b is negative (−(−7) = 7), (−7)² entered as −7² = −49, or 2a written as 2.
- Rounding too early, or giving only one solution when there are two.
- Completing the square with a ≠ 1 without taking a out first; or giving the turning point as (p, q) instead of (−p, q).
- Not rejecting (or not explaining the rejection of) a negative length or time.
- In "show that" questions, jumping steps or not reaching exactly the given equation.
