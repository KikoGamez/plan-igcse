# Algebra: inequalities, sequences and variation

> **In the exam:** All three come up in almost every series, in **both papers**. Inequalities: solve a linear inequality (2 marks), list integers that satisfy a double inequality (2–3 marks), or find/shade a region on a grid (3–5 marks). Sequences: next term and nth term of linear, quadratic, cubic and exponential sequences, often in one question worth 5–8 marks (Paper 2 or Paper 4). Variation: "y is directly/inversely proportional to…" worth 3–4 marks, very often on Paper 2.

## What you need to know

- Represent and interpret inequalities, including on a number line.
- Construct, solve and interpret linear inequalities.
- (Extended) Represent and interpret linear inequalities in two variables graphically; list inequalities that define a given region.
- Continue a given number sequence or pattern; recognise patterns in sequences and the relationships between different sequences.
- Find and use the nth term of sequences: linear, simple quadratic and cubic, and (Extended) quadratic, cubic and exponential sequences and combinations of these.
- (Extended) Express direct and inverse proportion in algebraic terms and use this form of expression to find unknown quantities.

## Notes

### Linear inequalities

Solve like an equation, with one extra rule: **multiplying or dividing by a negative number reverses the inequality sign**.

- 3 − 2x < 11 → −2x < 8 → **x > −4**. (Or avoid it: 3 − 11 < 2x → −4 < x.)
- 5x + 2 ≥ 3x − 8 → 2x ≥ −10 → x ≥ −5.
- **Double inequalities:** do the same to all three parts. −5 < 2n + 1 ≤ 9 → −6 < 2n ≤ 8 → −3 < n ≤ 4. Integers: −2, −1, 0, 1, 2, 3, 4.
- Number line: **open circle** for < or >, **filled circle** for ≤ or ≥.
- Answer must be an inequality (x > −4), not an equation (x = −4).
- "Integer values" — read carefully whether the ends are included.

### Inequalities on a graph (Extended)

1. Draw each boundary line (x = a vertical, y = b horizontal, y = mx + c sloped). The question may tell you to use solid lines; follow its instructions.
2. Test a point not on the line (often (0, 0)) to decide which side satisfies the inequality.
3. Shade as instructed — read whether you shade the **wanted** region (label it R) or the **unwanted** regions.
4. To **find** inequalities from a given region: find the equation of each boundary line, then use a point inside the region to choose the sign.
Example: a region below y = x + 2, to the right of x = 1 and above y = 0 is described by y ≤ x + 2, x ≥ 1, y ≥ 0.

### Sequences

| Type | How to spot it | nth term |
|---|---|---|
| Linear | constant first difference d | dn + (first term − d) |
| Quadratic | constant **second** difference | an² + bn + c, with a = (second difference) ÷ 2 |
| Cubic | constant third difference; compare with 1, 8, 27, 64 | e.g. n³ + 1 |
| Exponential (geometric) | constant **ratio** r | a × rⁿ⁻¹ |

**Linear:** 5, 8, 11, 14 → difference 3 → 3n; 3n gives 3, 6, 9…, add 2 → **3n + 2**.
Decreasing: 20, 17, 14, 11 → −3n + 23 → **23 − 3n**.
Is 100 a term of 3n + 2? 3n + 2 = 100 → n = 32.67, not a whole number, so **no** — give this reason.

**Quadratic:** 4, 9, 18, 31, 48
- First differences: 5, 9, 13, 17. Second difference: 4 → a = 2, so 2n².
- Subtract 2n² (2, 8, 18, 32, 50): remainder 2, 1, 0, −1, −2 → −n + 3.
- nth term = **2n² − n + 3**. Check n = 3: 18 − 3 + 3 = 18 ✓.

**Know these sequences:** squares n², cubes n³, triangle numbers ½n(n + 1), powers of 2: 2ⁿ.
Combinations: 2, 6, 12, 20 = n(n + 1) = n² + n; 3, 10, 29, 66 = n³ + 2.

**Exponential:** 3, 6, 12, 24 → ratio 2 → **3 × 2ⁿ⁻¹**. 48, 24, 12, 6 → ratio ½ → 48 × (½)ⁿ⁻¹.

### Direct and inverse variation (Extended)

| Words | Formula |
|---|---|
| y is (directly) proportional to x | y = kx |
| y is proportional to the square of x | y = kx² |
| y is proportional to the cube of x | y = kx³ |
| y is proportional to the square root of x | y = k√x |
| y is inversely proportional to x | y = k/x |
| y is inversely proportional to the square of x | y = k/x² |
| y is inversely proportional to the square root of x | y = k/√x |

**Method:**
1. Write the formula with k.
2. Substitute the given pair of values to find k.
3. Write the formula with the value of k (often a mark for this).
4. Substitute to find the unknown.

Example: y ∝ x², y = 12 when x = 2 → 12 = k × 4 → k = 3 → y = 3x². When x = 5, y = 75. When y = 48, x² = 16, x = 4 (for x > 0).

**Effect of a change:** if y = kx³ and x is doubled, y is multiplied by 2³ = 8. If y = k/x² and x is doubled, y is divided by 4 (multiplied by ¼).

## Worked examples

**1.** Find the integer values of n that satisfy −5 < 2n + 1 ≤ 9. [3]

- −6 < 2n ≤ 8 or −3 < n ≤ 4 — **M1** (allow for one side correct)
- **−2, −1, 0, 1, 2, 3, 4** — **A2** (A1 for six correct and none wrong, or seven correct and one extra)

**2.** The sequence 4, 9, 18, 31, 48, … is quadratic. Find an expression for the nth term. [3]

- second difference 4 seen — **M1**
- 2n² seen in the expression — **M1**
- **2n² − n + 3** — **A1**

**3.** y is inversely proportional to the square root of x. When x = 4, y = 6.
(a) Find y in terms of x. [2]
(b) Find y when x = 9. [1]

- (a) y = k/√x, 6 = k/√4 — **M1**; **y = 12/√x** — **A1**
- (b) 12/3 = **4** — **B1** (follow through their k)

## Common mistakes

- Not reversing the inequality sign when dividing by a negative.
- Giving x = −4 (an equation) as the answer to an inequality question.
- Including an end value that should be excluded (or the reverse) when listing integers.
- Linear nth term written as n + 3 for 5, 8, 11 (using the first term instead of the difference), or writing 3n + 2 as "n + 3".
- Quadratic sequences: using the second difference as a instead of halving it.
- Exponential sequences: writing 3 × 2ⁿ instead of 3 × 2ⁿ⁻¹ (check n = 1).
- Variation: using y = kx when the question says "square", or forgetting to find k before the second part.
- Shading the wrong region, or not following the instruction about wanted/unwanted regions.

## Practice questions

1. Solve 5x + 2 ≥ 3x − 8. [2]
2. Find the largest integer x such that 7(x − 1) < 30. [2]
3. Find the nth term of 20, 17, 14, 11, … [2]
4. Find the nth term of 3, 6, 12, 24, … [2]
5. Find the nth term of 2, 7, 14, 23, 34, … [3]
6. Find the nth term of 2, 9, 28, 65, … [2]
7. F is inversely proportional to the square of d. F = 20 when d = 3. Find F when d = 6. [3]
8. y is proportional to x³. Describe the effect on y when x is doubled. [1]
9. Is 150 a term of the sequence with nth term 4n − 2? Give a reason. [2]

<details><summary>Answers</summary>

1. 2x ≥ −10 → **x ≥ −5**
2. 7x − 7 < 30 → x < 37/7 = 5.28… → **x = 5**
3. **23 − 3n**
4. **3 × 2ⁿ⁻¹**
5. second difference 2 → n²; remainder 1, 3, 5, 7, 9 = 2n − 1 → **n² + 2n − 1**
6. **n³ + 1**
7. 20 = k/9 → k = 180 → F = 180/36 = **5**
8. y is **multiplied by 8**
9. 4n − 2 = 150 → n = 38, a whole number → **yes**, it is the 38th term.
