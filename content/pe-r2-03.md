# Mark the paper with the mark scheme

> **Goal:** Mark your Paper 1 using the Cambridge mark scheme the way an examiner does, find where marks were lost and why, and start an error log you will use in the next session.

## Before you start

- **Material:** your completed Cambridge IGCSE PE (0413) Paper 1 from the previous two sessions (e.g. May/June 2024 Paper 12) and its **mark scheme** (same series and variant, from your teacher or the Cambridge past-papers area). Also the principal examiner's report if you can get it (it lists common errors).
- A red or green pen (different colour from your answers), highlighter, error log (a table: question, topic, marks lost, reason, correct answer).
- Timer: 60 minutes.

## Exam format reminder

- Mark schemes list **mark points** separated by "/" for alternatives and ";" for separate marks. You get one mark per valid point up to the maximum shown. Wording does not need to be identical if the meaning is the same.
- **AO1** = knowledge, **AO2** = apply and evaluate. Note which kind of marks you lose most often.
- "Do not accept" and "ignore" notes show common wrong answers.
- Total: 100 marks. Use the grade boundaries from the series (if published) only as a rough guide; your teacher's boundaries for the mock matter more.

## How to do it

1. **0–5 min:** Read the first page of the mark scheme (general marking principles and abbreviations).
2. **5–40 min:** Mark every question. For each: tick each mark point you earned, write the mark in the margin, and if you lost marks write the **missing mark point** in coloured pen. Be strict: if the mark scheme says "must name the muscle" and you wrote only "leg muscle", do not give the mark.
3. **40–45 min:** Add up the total and each section. Calculate your percentage.
4. **45–58 min:** Fill the error log for every lost mark. Use these reason codes:
   - **K** = did not know the fact/term
   - **C** = misread the command word (e.g. described instead of explained)
   - **A** = not applied to the sport/context
   - **V** = too vague/repeated point
   - **S** = silly mistake (calculation, units, misread)
5. **58–60 min:** Count the reasons: which is the biggest? Write one rule for next time.

## Exam technique for this paper

- If you lost marks for **C**, practise underlining the command word and writing a plan: command + number of marks = number of points.
- If **A**: add the sport name and a specific example in every answer.
- If **V**: replace general words with specific terms: "get tired" → "lactic acid build-up causes muscle fatigue".
- If **K**: schedule a learning slot for that topic (next session).
- Compare your answer to the mark scheme wording and learn the key phrase.
- Note which questions you left blank: blanks lose marks that a guess might earn.

## Checklist while marking

- Did I mark strictly, only giving marks for points in the mark scheme?
- Did I note the **missing** mark point, not just tick/cross?
- Did I write each error in the log with a reason code?
- Did I check for marks lost on definitions (e.g. exact definitions of health, fitness)?
- Did I check calculations (cardiac output, heart-rate zones)?
- Did I count marks per topic (anatomy, health/fitness/training, skill/psychology, social)?
- Did I identify the three topics with the most lost marks?

## Quick-fire revision

- Stroke volume × heart rate = cardiac output.
- Vital capacity: the maximum volume of air breathed out after a deep breath in.
- Tidal volume: air breathed in/out at rest. Minute ventilation = tidal volume × breathing rate.
- Alveoli: thin walls, moist, large surface area, many capillaries.
- Arteries: thick walls, small lumen, high pressure. Veins: thin walls, valves.
- EPOC: oxygen needed after exercise to remove lactic acid and restore the body.
- Plyometrics → power; continuous → cardiovascular endurance; weights → strength.
- Real risk v perceived risk.
- Extrinsic motivation: rewards from outside; intrinsic: enjoyment from within.
- Sponsorship: advantages and disadvantages for performer, sponsor, sport and audience.
