# Weekly review

> **Goal:** lock in everything you studied this week — review all of its flashcards, test yourself with 10 mixed questions across the week's topics, and bring the error log up to date so nothing you got wrong is forgotten.

This hour happens every Sunday. This week's topics are listed below this text: use that list to choose your questions.

## What to do (60 minutes)

| Time | Task |
|---|---|
| 0–20 min | Flashcards for the whole week |
| 20–45 min | 10 mixed questions, timed |
| 45–55 min | Mark and update the error log |
| 55–60 min | Plan next week's weak spots |

### 1. Flashcards (20 min)

- First do Anki's **due reviews** for all decks (do not skip any).
- Then use **Custom Study → "Review forgotten cards"** or browse the cards **added this week** (in the Browser: search `added:7`) and run through them once more.
- Any card you fail twice: rewrite it. Usually it is too long or vague — split it in two.
- Say answers aloud or write them; do not just "recognise" the back.

### 2. Ten mixed questions (25 min)

Pick **10 questions** from the week's topics, mixed so that no two in a row are from the same subject:
- Take 1–2 questions from the **practice questions** of each session page this week, choosing ones you got wrong or found hard (re-do them without looking at your old answer).
- Add 2–3 questions from older past papers on the same topics.
- Include at least **one "explain"/"describe" question** (sciences, Business), **one calculation** (Maths, Statistics, Physics, Chemistry) and **one language task** (e.g. translate five sentences into French, or write a 50-word paragraph in Spanish or English using a technique from this week).
- Time yourself: about **1 minute per mark** + a bit (Cambridge papers run at roughly 1–1.2 minutes per mark).
- Closed book. No notes until you have finished all ten.

### 3. Mark and update the error log (10 min)

- Mark with the answers on the session pages or the official mark scheme. Be strict: if the key word in the mark scheme is missing, the mark is lost.
- For every lost mark add a row to the error log: date, question, topic, what you wrote, correct answer, **error type** (Knowledge / Method / Careless / Technique), the fix.
- Make an Anki card for every Knowledge and Method error.
- **Re-test old rows:** choose 5 rows from earlier weeks that are not yet marked ✓. Cover the answer and do them again. Mark ✓ (fixed) or ✗ (still wrong — keep it for next week).

### 4. Plan next week (5 min)

- Filter the error log by **Type**. If most errors are *Careless*, your fix is a checking routine (re-read the question, units, significant figures). If most are *Technique*, re-read the "Exam technique" and "Common mistakes" sections. If most are *Knowledge*, you need more flashcard time.
- Write down the **two weakest topics** of the week. Add 10 minutes on each to the start of a session next week.

## Rules that make this work

- Never skip the weekly review, even if you are behind. It is worth more than one new topic.
- Questions before answers: struggling for a minute before checking is what makes you remember.
- Mixed beats blocked: switching subjects feels harder but is closer to the real exam and gives better long-term memory.
- Honest marking: half-right answers get the marks the mark scheme gives, not the marks you think you deserve.

## Checklist

- [ ] All Anki reviews due today done (every deck)
- [ ] This week's new cards reviewed once more; bad cards rewritten
- [ ] 10 mixed questions done, timed, closed book
- [ ] Marked strictly; every lost mark in the error log with an error type
- [ ] New Anki cards made from Knowledge/Method errors
- [ ] 5 older error-log rows re-tested and marked ✓/✗
- [ ] Two weakest topics written down for next week
